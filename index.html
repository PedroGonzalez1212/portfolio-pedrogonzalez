Diseño de producto

La mayoría de mis diseños no son solo estética: son sistemas de diseño lógicos y escalables, pensados específicamente para web y aplicaciones. Con foco fuerte en diseño UI y pensamiento sistémico, busco crear elementos y módulos responsivos, flexibles y, sobre todo, funcionales y performantes.

Creo firmemente que el UI tiene un impacto directo en tu marca y en tus soluciones web — ahí es donde empieza mi interés real: unir todas las piezas clave para que cada decisión tenga un valor concreto.

Desarrollo web

Traducir el diseño en experiencias web dinámicas y funcionales es donde más disfruto trabajar. Me apasiona transformar sistemas de diseño en entornos web reales, escribiendo código a medida (HTML, CSS y JS) para crear sitios sostenibles, con componentes flexibles y responsivos.

Ya sea construyendo soluciones animadas o armando módulos reutilizables, mi objetivo es desarrollar sitios que no solo se vean bien, sino que estén construidos para durar. Se trata de unir creatividad y lógica para lograr experiencias fluidas que se sientan frescas y se adapten a cualquier dispositivo.

Puedo ser la persona indicada para vos no solo por el diseño UI o el desarrollo, sino porque pienso en función de la visión de marca y le doy propósito a cada pixel.

ABOUT ME

Soy desarrollador web y diseñador UX/UI, y no divido el proceso en "el que diseña" y "el que programa" — lo hago yo, de punta a punta. Eso cambia el resultado: las decisiones de diseño ya nacen pensando en cómo se van a construir, y el código no traiciona la idea original en el camino.

Trabajo con HTML, CSS y JavaScript para construir interfaces que funcionan tan bien como se ven, y con Python cuando el proyecto lo necesita del otro lado. Pero antes de abrir el editor, lo que me interesa es entender el problema real: quién va a usar esto, qué necesita lograr, y qué es lo mínimo necesario para que funcione bien.

Sigo aprendiendo todo el tiempo — el desarrollo web no se queda quieto, y yo tampoco. Si trabajás conmigo, no coordinás a un diseñador y a un desarrollador por separado ni traducís entre los dos: hay una sola visión, de la idea al sitio funcionando.
